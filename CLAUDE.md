# Regras PrismView & Economia
- Respostas ultra-curtas. Sem saudações, introduções ou resumos longos.
- Nunca leia `node_modules/`, `target/`, `.git/`, `dist/`, `.glb`, `.gltf`, `.png`, `.jpg`, `package-lock.json`.
- Leia apenas os arquivos estritamente necessários para a tarefa atual e aplique patches pontuais.
- Regras técnicas: nunca alocar objetos/vetores dentro de loops de render 60–144 FPS; sempre chamar `dispose()` em geometrias, materiais e texturas 3D descartadas (exceto texturas compartilhadas em cache).

# Projeto
- PrismView Studio: wallpapers/widgets animados, só Windows. Tauri 2 + React 18 + Three 0.187 + Tailwind 3 + Vite 6 + framer-motion + lucide-react.
- Raiz app: `apps/prismview-studio/`. Scripts: `npm run dev` (porta 1420 strict), `npm run build` (tsc + vite), `npm run tauri`. Sem testes/lint.
- Duas entradas Vite (`vite.config.ts`): `index.html`→`src/App.tsx` (Hub + Studio, janela `main`) e `desktop.html`→`src/desktop.tsx` (leve: sem Hub/Studio/framer-motion). Chunks: `three-core`; `three-editor` (gizmos Sala 3D, só Studio).
- `desktop.tsx` por query: `?monitor=<id>` = wallpaper (anexado ao WorkerW, 1 por monitor, `interactive=false`); `?mode=widget&id=<id>` = widget transparente standalone (drag/lock/unpin).
- Dados em `%APPDATA%\PrismView\` (`projects/<id>.json`, `packages`, `imports`, `fonts`, `assets`, `session.json`). Pacote `.prism` = zip.
- Tauri: CSP null, asset protocol scope `**`, `bundle.active=false`.

# Frontend (`src/`)
- `types/prism.ts` (~1800 linhas): fonte dos tipos/defaults/templates. `PrismProject`, `SceneLayer`, `Scene3DConfig` (schema v2, FPS 5–200), `ReactiveSignal`, `LiveTelemetry`, `invokeCmd`, `isTauriRuntime`, `resolveMediaUrl`, `normalizeProjectScene3D`, `evaluateFormula` (avaliador FX em TS), `create*Project`.
- `components/UnifiedCompositor`: renderiza camadas (texto/SVG/vídeo/vidro/3D). `Scene3DLayer` carregado via `React.lazy`. SVG passa por `sanitizeSvgMarkup`.
- `components/Scene3DLayer`: cena Three (renderer, PMREM, loaders GLB, bindings reativos, texturas dinâmicas, editor Sala 3D via `Scene3DEditorApi`).
- `components/OpticalGlassSurface` + `utils/opticalGlassWebGL` (backdrop, pirâmide de blur) + `utils/glassLens`: vidro óptico.
- `components/StudioEditor` / `StudioInspector`: editor de camadas; `FxExpressionPopover`: fórmulas FX; `utils/layerTree`: árvore/grupos; `utils/scene3dEditorTools`: gizmos/snap.
- `engine/scene3d/`: `environment`, `loaders` (loaders compartilhados retain/release, Draco/Basis em `public/decoders`), `modelIndex` (`disposeObject3D`, `restoreBaseMaps`), `sculptures` (showcase procedural).
- `engine/powerGovernor`: preferência AUTO/NORMAL/ECO/ULTRA/FROZEN em `localStorage` (`prismview.powerPreference.v1`), compartilhada entre janelas; AUTO usa bateria (ULTRA ≤20%, sai >25%). `powerCapsFor` dá fpsCap/dprCap/renderScaleCap/flags. Respeitar caps em todo loop de render novo.
- `hooks/useDesktopWindowBridge`: ouve eventos antes do handshake `*_window_ready`; cursor coalescido por rAF (sem re-render); telemetria congelada quando oculto. `useHistory` (undo/redo), `useKeyboardShortcuts`.
- Eventos Tauri: `prism://telemetry` (~1.5 s), `prism://reactive`, `prism://cursor`, `prism://cursor-click`, `prism://visibility-changed`, `prism://wallpaper-scene`, `prism://widget-scene`, `prism://monitor(s)-changed`.

# `crates/prismview-engine` (motor nativo, Fase 0 em andamento)
- Meta (PLANO_NATIVO.md, fora do repo, em `Downloads`): wallpaper 100% nativo Rust + wgpu (DX12) + Win32, sem WebView; Studio Tauri só edita. Fases: 0 Win32/WorkerW/wgpu base → 1 compositor 2D/texto/vídeo zero-copy → 2 vidro WGSL → 3 3D glTF/PBR → 4 SignalBus → 5 PowerGovernor + IPC com Studio. 1 fase por sessão.
- Regras do plano: zero `unwrap/expect` no loop de render (SurfaceError::Lost/Outdated → recriar swapchain); zero alocação por frame (buffers pré-alocados + `.clear()`); render targets só recriados em resize/troca de asset; vídeo sem cópia/conversão BGRA→RGBA na CPU; `core/` (futuro: gpu, glass, scene3d, text, signals, governor) nunca importa código de SO — só fala via traits de `platform/mod.rs`.
- `main.rs` (~2500, LEGADO, binário `windows_subsystem`): host Win32 próprio (`win32_host`, WorkerW), render wgpu + ab_glyph, IPC named pipe (`ipc_server`), tray, GSMTC. Ainda NÃO usa `platform/` (declarado com `#[allow(dead_code)] mod platform;`). `video.rs`: decoder antigo. `shaders/liquid_glass.wgsl`.
- `platform/mod.rs`: traits neutras `DesktopHost`, `HardwareVideoDecoder`, `SystemSensors` + tipos (`MonitorInfo`, `DesktopEvent`, `DesktopVisibility`, `NativeWindowId`, `PlatformError`); `UnsupportedPlatform` para não-Windows.
- `platform/windows/` (só `DesktopHost` implementado; vídeo/sensores TODO):
  - `mod.rs`: `Win32DesktopHost::new(HostConfig)` (1 por thread, `!Send`), `create_wallpaper_window(monitor_id)`, `monitor_visibility`/`window_visibility` (pausa por monitor), `wallpaper_windows()` (refazer superfícies wgpu após `ShellRestarted`), `proxy()`.
  - `workerw.rs`: `discover()` → `DesktopLayer` `Legacy` (Win10/11≤23H2: filho do WorkerW atrás dos ícones) ou `Raised` (24H2+: filho do Progman abaixo do `SHELLDLL_DefView`, WorkerW movido abaixo). Timeout + `SMTO_ABORTIFHUNG`, valida PID do Explorer.
  - `monitors.rs`: PMv2, pixels físicos, DPI por monitor; id = `\\.\DISPLAYn`.
  - `win_events.rs`: `SetWinEventHook` out-of-context; LOCATIONCHANGE só do processo em foreground.
  - `visibility.rs`: cobertura por monitor (maximizado, bounds ⊇ monitor, D3D fullscreen; ignora cloaked/transparente/shell). Só sob evento.
  - `signals.rs`: thread-local `Cell` de bits + timers de debounce no controlador. Callbacks/wndprocs NÃO fazem trabalho pesado nem usam `RefCell` (reentrância); processamento em `process_signals`.
  - `window.rs`: superfície (WM_PAINT → `ValidateRect` + sinal REPAINT, HTTRANSPARENT) e controlador oculto top-level (broadcasts, `TaskbarCreated`, WTS lock, `WM_PRISM_WAKE/EXIT`).
  - `event_loop.rs`: `run(host, handler: impl LoopHandler)` com `ControlFlow::{Wait, WaitUntil, Poll, Exit}` via `MsgWaitForMultipleObjectsEx` + waitable timer alta resolução; `LoopProxy` (Send) acorda/encerra.
- Pendências Fase 0: `core/gpu.rs` (wgpu DX12, LowPower padrão), comando src-tauri para iniciar/parar o motor, detecção de monitor desligado, ligar `main.rs` ao `platform/`. Risco: `WS_EX_LAYERED` no 24H2 + swapchain DX12 (desligar `HostConfig::layered_on_raised_desktop` se ficar preto).
- Fase 1 (2D + texto; escrita SEM compilar): `core/compositor.rs` (`Compositor2D` pipelines/texturas + `Canvas` por monitor, quads instanciados, blend Normal/Plus/Multiply/Screen), `shaders/compositor2d.wgsl` (SDF cantos arredondados, borda, gradiente, máscara de clip, sombra; alpha pré-multiplicado, formato não-sRGB), `core/text.rs` (`TextSystem` glyphon 0.8/cosmic-text 0.12: 1 slot+textura branca por camada, dirty por chave, fontes do projeto via `register_font_dir`, sistema só sob demanda), `core/scene2d.rs` (`SceneRenderer`: `PrismScene`→quads; z = pré-ordem; refaz lista só se versão/tamanho/DPI mudou; `advance_clock`/`next_wake`). `native.rs` trata `LOAD_SCENE`. - Vídeo zero-copy (escrito SEM compilar): `platform/windows/video.rs` `MfVideoDecoder` impl `HardwareVideoDecoder` (trait ganhou `bind_gpu`, `advance`, `current_gpu_frame`→`GpuVideoFrame`, `time_until_next_frame`, `last_error`). # Armadilhas
- Wallpaper é outro WebView: `blob:` URL não atravessa; salvar caminho real/asset (`PickedFileDto` via `pick_local_file`).
- Backdrop 3D do vidro é canvas `live`: re-upload por frame.
- Textura dinâmica (capa de música) vem de `dynamicTexCache`: compartilhada, não dar `dispose()` ao descartar modelo; devolver `baseMap` antes.
- Perda de contexto WebGL: refazer PMREM/ambiente no restore.
- Hub: miniaturas usam `HubThumbnail` (memo, telemetria fixa, `paused`); cada uma pode custar um WebGL.
- `AUDITORIA.md`: bugs/vazamentos priorizados (Etapa 1 primeiro). Consultar antes de mexer em 3D/vidro.
- Lixo/backup, ignorar: `_backup_antes_sala3d/`, arquivo `e.restoreContext()`. `.claudeignore` espelha a lista de não-leitura.
